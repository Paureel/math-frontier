# Local development

This repository is separate from integer-mult-bounds-viz. Keep all work local.
Do not push, register a ChatGPT Site, upload source, publish, deploy, or republish
unless the human user explicitly requests that action for this task.

Preserve source provenance and evidence scope. A proposed or conditional bound,
a formalization target, and a maintainer selection are different states.
Do not rank unrelated metrics or represent exponent improvements as runtime benchmarks.

Use `npm test` for research-data changes and `npm run build` for source changes.
Keep tokens server-side and environment files untracked.

Never promote a PR title/body, merge status, CI badge, search result, or README
number into a reviewed frontier result. Only supported immutable upstream review
receipts can pass the shared claim policy. Preserve conditional scope; a finite
audit is not an independently verified full theorem. Failed or unsupported
updates must not silently retain a current review/comparison label.

Reject uninspected selections before following their claimed PR or receipt paths.
Check all explicit PR bound assignments so a matching decoy cannot hide a
contradictory number. PR metadata never supplies a frontier value. Preserve the
closed local evidence registry and exact editorial comparison baseline; adding
a reviewed result requires an explicit owner review of its evidence and scope.
Reject unsupported verification/derived-best fields in cache and API records.

Do not add Following, accounts, analytics, cookies, browser persistence, or saved
visitor preferences. Keep exploration state in memory. Public research caching
is allowed; it must never include visitor identifiers or interactions.

Repository discovery is manual and owner-triggered only. Preserve the bundled
discovery list during page/API refreshes, timers, visibility changes and source
sync. Never run a discovery scan unless the owner explicitly requests it. Only
the local `npm run discover` command or an explicit owner edit changes that list;
runtime caches cannot replace it. Do not expose discovery through a visitor API.

Preserve each release model and its quantifiers, probability/error guarantees,
and reported formalization scope. Never equate a linked Lean file with the full
manuscript. Review receipts must match the locally inspected content registry;
new source content, CI success, or cached labels cannot approve themselves.
Mark rounded numeric displays as approximations and keep unreviewed badges
visible at every screen size.

Proof-component refinements and method barriers are supporting contributions,
with null headline values and locally fixed contribution descriptions. Never
display proof-grid edges as an exponent, an internal counting constant as a
whole-construction dimension, or a template minimum as a global optimum.
